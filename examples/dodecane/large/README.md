# Large-scale dodecane example (500 molecules, united atom, 298 K)

500 dodecane molecules (6 CG beads, 12 united-atom sites each), 57.5376 A box,
0.742 g/cm3. CG model and configuration from the JCTC 2016 dodecane data
(`preparation/dodecane/cg_force_field`, including the tabulated CG angles and
dihedrals); AT model: `topol_aa.top`.

Every force field is generated by `backmap-prep`; the `in.*` scripts here are
protocol only.

| Step | Command | Output |
|---|---|---|
| Build | `backmap-prep build settings.yaml` | `dodecane.data`, `in.dodecane` (robust protocol), `dodecane.ff.lmp`, `dodecane.backmap.lmp`, `dodecane.at.ff.lmp`, tables |
| Tier B | `lmp -in in.dodecane` | `dodecane_hybrid.data` (lambda = 1) |
| AT frame | `backmap-prep at-system settings.yaml --from dodecane_hybrid.data` | `dodecane_at.data` |
| Tier C | `lmp -in in.dodecane_at` | `rdf_backmap.dat` |
| Reference | `backmap-prep at-system settings.yaml --reference 500` then `lmp -in in.dodecane_at_ref -var L 57.5376` | `rdf_reference.dat` |

`run_tier_bc.sh backmap|reference` runs the chain (set `LMP`, `NP`,
optionally `PROD_STEPS`). `backmap-prep cg-only` writes the CG equilibration
input (`in.dodecane_cg_equil`). Compare with `compare_rdf_blocks.py`.
