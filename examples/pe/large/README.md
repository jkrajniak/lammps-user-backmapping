# Large-scale PE example (75 chains, united atom, 423 K)

75 chains of 100 united-atom sites (50 CG beads each), 60.1855 A box,
0.80 g/cm3. CG model and configuration from the JCTC 2016 polyethylene data
(`preparation/pe/cg_force_field/nvt`); AT model: `topol_aa.top`.

Every force field is generated by `backmap-prep`; the `in.*` scripts here are
protocol only.

| Step | Command | Output |
|---|---|---|
| Build | `backmap-prep build settings.yaml` | `pe.data`, `in.pe` (robust protocol), `pe.ff.lmp`, `pe.backmap.lmp`, `pe.at.ff.lmp`, tables |
| Tier B | `lmp -in in.pe` | `pe_hybrid.data` (lambda = 1), thermo with all energy terms |
| AT frame | `backmap-prep at-system settings.yaml --from pe_hybrid.data` | `pe_at.data` |
| Tier C | `lmp -in in.pe_at` | `rdf_backmap.dat` |
| Reference | `backmap-prep at-system settings.yaml --reference 75` then `lmp -in in.pe_at_ref -var L 60.1855` | `rdf_reference.dat` |

`run_tier_bc.sh backmap|reference` runs the chain (set `LMP`, `NP`,
optionally `PROD_STEPS`). Compare with `compare_rdf_blocks.py`.
