# 10-Chain Dodecane: Backmapping Quick Start

Backmapping of 10 dodecane (C12H26) molecules from CG to atomistic resolution.
This is the small, laptop-sized version of [`large/`](large/README.md) (500 molecules).

## System

- **10 chains**, 180 atoms total (60 CG beads + 120 AT atoms), 57.5376 A cubic box
- CG model: 6 beads per chain (A1, B1-B4, A2) with the published tabulated IBI
  interactions, bonds, angles and dihedrals of the JCTC 2016 dodecane model
- AT model: united-atom GROMOS 53a6 (`topol_aa.top`, CH3 / CH2)

Per-chain mapping:

| CG bead | AT atoms | AT types |
|---------|----------|----------|
| A1      | C1, C2   | CH3, CH2 |
| B1-B4   | C3-C10 (two per bead) | CH2, CH2 |
| A2      | C11, C12 | CH2, CH3 |

## Workflow

Every force field and data file is generated by `backmap-prep`; the `in.*`
scripts here are protocol only. Type ids are assigned by the generator
(A = 1, CH3 = 2, CH2 = 3, B = 4 in the hybrid file), so use the commands below
and not hand-written atom-type lists.

```bash
uv run backmap-prep build settings.yaml                      # data, force fields, tables, in.dodecane
lmp -in in.dodecane                                          # backmapping, writes dodecane_hybrid.data
uv run backmap-prep at-system settings.yaml --from dodecane_hybrid.data   # dodecane_at.data
lmp -in in.dodecane_at -var prod_steps 200000                # atomistic continuation
```

The 10 chains sit in the box of the 500-molecule melt, so this system is a
**dilute gas of chains** (about 0.015 g/cm3), not a melt. It shows the mechanics
of the workflow in minutes; it is not a structural test, and RDFs from it cannot
be compared with a melt reference. The validation (RDFs against an independent
atomistic melt) is in [`large/`](large/README.md).

## Files

| File | Description |
|------|-------------|
| `settings.yaml` | backmap-prep configuration |
| `topol_cg.top`, `topol_aa.top`, `cg_conf.gro`, `dodecane_single.gro` | CG and AT topologies and coordinates |
| `table_*.xvg` | Published CG tables (converted to `table_*.table` by `build`) |
| `in.dodecane` | Generated backmapping input (robust protocol) |
| `in.dodecane_at` | Atomistic continuation (protocol only; the force field is `dodecane.at.ff.lmp`) |
| `prepare_cg.py` | Cuts the pure CG system out of a hybrid data file (used for [`../dodecane-lammps-cg`](../dodecane-lammps-cg/README.md)) |
| `single_chain/` | One-chain system with visualisation scripts (paper Fig. 1 snapshots) |
